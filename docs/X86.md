# 32-bit build and installation

The x86 component targets 32-bit foobar2000 2.x Default UI, including on 64-bit Windows. Install the win-x86.fb2k-component package. Never replace foobar shared.dll.

Use the common complete source archive in a separate directory from x64 builds:

```powershell
./scripts/build-x86.ps1
./scripts/test.ps1 -Architecture x86
./scripts/package-x86.ps1 -SkipBuild -SkipTests
```

The build script compiles the SDK Win32 shared import library from source and checks the resulting PE architecture. See BUILD.md for Visual Studio prerequisites. Do not mix architecture-specific build objects.

32-bit address space limits can affect very long tracks/waveforms/stems. The optional stems engine runs as a separate process; supported PyTorch installation requires 64-bit Windows/Python. The component works without it. Compilation and native tests pass; real-host x86 feedback remains requested.
