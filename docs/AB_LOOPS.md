# Independent A/B loops / Boucles A/B indépendantes

## Français

**Option Q (0.36.2)** : bouton à droite de la rangée A/B, indépendant sur chaque platine. Grisé = libre ; allumé = nouveaux points A/B calés sur le trait affiché le plus proche. Le choix est conservé après redémarrage. Activer Q recale aussi les points A/B déjà posés et sauvegarde immédiatement leurs nouvelles positions. Si seul A est posé, il est recalé seul. Si Q est déjà allumé, l’éteindre puis le rallumer pour recaler après un changement de grille ou de zoom. Éteindre Q ne déplace pas les points. En l’absence de grille ou si deux points distincts ne peuvent pas tenir dans les bornes du morceau, les anciens points et le réglage Q sont conservés, avec une indication. La lecture/pause est conservée ; une boucle active revient à A si la nouvelle zone exclut la position actuelle.

Le calage reprend exactement la phase de la grille affichée : manuelle en priorité, sinon estimée, sinon BPM indicatif en pointillés. Ce dernier cas ne garantit pas de vrais battements audio. Le zoom détermine les traits disponibles : zoomer jusqu’à « 1 trait / 1 temps » pour choisir chaque battement, ou garder une grille plus espacée. Si la ligne la plus proche ne permet pas un B après A, la ligne admissible suivante est choisie. Sans BPM/grille ou trait admissible entre les bornes du morceau, le placement est refusé avec une indication. Modifier la grille ou le zoom ne déplace pas les points déjà posés. Les positions restent enregistrées en temps source, sans changer avec la vitesse de lecture.


Sous chaque forme d’onde :

1. Lire ou mettre en pause à la position souhaitée, puis cliquer **A** pour poser le début.
2. Aller plus loin, puis cliquer **B** pour poser la fin (au moins 100 ms après A).
3. Cliquer **A-B OFF** : retour à A et activation. Le bouton devient **A-B ON**. Une platine en pause reste en pause ; Lecture lance alors la boucle.
4. Cliquer **A-B ON** pour désactiver sans effacer les points ; le morceau continue normalement. **×** efface A et B.

Les boutons affichent les positions et les repères A/B apparaissent sur la forme d’onde. Les infobulles expliquent les commandes. Les deux platines peuvent boucler indépendamment. Désactiver avant de modifier les points. Un positionnement dans la boucle la conserve ; un positionnement hors de la boucle (y compris Début ou SYNC) la désactive sans effacer A/B.

AUTO conserve son mode : la liste de la platine en boucle n’avance pas ; l’alternance A/B attend tant qu’une boucle est activée, même si cette platine est en pause. Désactiver la boucle pour reprendre AUTO. L’activation est refusée pendant un fondu AUTO déjà commencé ; attendre sa fin. Le bouton Arrêter/libérer conserve les points pendant cette session et libère toujours les lecteurs.

Les points A/B sont sauvegardés automatiquement par chemin canonique du morceau et numéro de sous-piste dans `foo_dj-loops.json`, dans le profil foobar. Ils reviennent au rechargement, sur l’une ou l’autre platine, même après fermeture de foobar. Un point A seul est également conservé. **×** efface les points sauvegardés du morceau. La boucle revient toujours désactivée ; cliquer ON pour la reprendre. Si le même morceau est ouvert sur les deux platines, la dernière modification détermine les points sauvegardés ; les points déjà chargés sur l’autre platine restent indépendants. Les points devenus incompatibles avec la durée ou les limites de silence sont ignorés au chargement. Renommer ou déplacer le fichier change son association. Ce JSON contient des chemins locaux : ne pas le publier sans les masquer. En cas d’échec d’écriture, les points restent en mémoire avec une indication ; une sauvegarde ultérieure de session réessaie. Les fichiers audio et leurs tags ne sont pas modifiés. Les boucles sont manuelles, sans quantification automatique sur les battements. Elles suivent le tempo, la transposition, les stems et la préécoute Cue A/B du deck. Les extraits de préécoute de playlist restent indépendants.

Le moteur revient à A à la limite de bloc audio de B, en découpant le bloc commun aux deux platines. Il vide les tampons de décodage et de traitement pour éviter de rejouer la fin précédente. La précision temporelle est limitée à une image audio de sortie multipliée par la vitesse ; la latence de sortie s’applique toujours aux commandes. Une coupure audible reste possible si A/B ne correspondent pas à des passages par zéro, ou avec certains décodeurs/traitements : pas de promesse de boucle sans clic ni de boucle musicale parfaitement quantifiée.

## English

**Q option (0.36.2)**: the rightmost A/B-row button enables snapping for new points on that deck. Grey = free; highlighted = quantized. The per-deck choice persists. Enabling Q also snaps existing A/B points (or A alone) and saves the new positions. Turn Q off/on again to resnap after a grid/zoom change. Disabling Q leaves points unchanged. Missing grids or an impossible pair leave both points and Q state unchanged with a notice. Transport is retained; an active loop seeks to A if its new bounds exclude the current position. Manual, estimated and dotted indicative grids share exactly the same phase used for display. Dotted grids do not guarantee real musical beats. Snapping uses the visible line stride at the current zoom; zoom to one line per beat for individual beats. The nearest admissible line is selected inside track/trim bounds and after A for B. Missing grids or no admissible line reject placement. Later grid/zoom edits do not move existing saved points; positions use source time regardless of playback speed.


Each deck has **A**, **B**, **A-B OFF/ON** and **×** below its waveform. Set A, set B at least 100 ms later, then enable: the deck seeks to A and retains play/pause. Disable to continue normally; × clears both points. Point positions and waveform markers are shown, with bilingual tooltips.

Loops are independent and manual, with no beat quantization. Seek inside to keep looping; seek outside (including Start or SYNC) disables it but retains points. Disable before editing points. A/B points (including A alone) are saved by canonical file path and subsong in the profile’s `foo_dj-loops.json` and restored on either deck, across restarts. The loop is always disabled on load. × removes the saved points. Last edit wins for a shared track; an already loaded second deck remains independent. Points outside the current duration/trim bounds are ignored. Renaming/moving the file changes its association. The JSON contains private local paths; redact before sharing. Failed writes keep points in memory and show a non-fatal notice; later session saves retry. Audio files/tags are untouched. Stop/Release retains points in memory while closing readers.

AUTO mode is retained: the looping queue does not advance, and alternating A/B waits while either loop is enabled, including a paused loop. Disable to resume AUTO. Enabling during an active automatic fade is refused. Tempo, key lock, pitch, stems and deck headphone cue follow the loop; independent playlist preview excerpts do not.

Audio boundaries split the shared output block, seek the appropriate original/stem reader and discard decoder/stretch lookahead. Timing is rounded to an output frame at the current speed. Output latency still applies. Decoder seeks, non-zero boundary samples and processing resets can produce clicks/artifacts; seamless or beat-quantized musical looping is not guaranteed.
